A learning resource for epilepsy physicians, colleagues, and fellows, covering anatomy, stimulation responses, mechanisms, primary-study findings, and interpretation. The manual links primary sources and attributes PAROS Epilepsy 2026 conference teaching and hypotheses.

## Review status

This is an educational review draft. Named clinical signoff is pending. Operating settings and clinical procedures require the effective local protocol. It is not an approved clinical guideline or final print edition. The source review combines selected transcript passages, targeted primary literature, and the existing source-audit trail; it is not full VOD verification or a new systematic review.

## How to contribute

Use the review link beneath a chapter, or [open a review comment](https://github.com/erafat/cortical-stimulation-manual-review/issues/new?template=chapter-review.md). Please identify the chapter, heading, sentence, concern, and suggested correction. Add a primary reference where useful. See [review guidance](REVIEWING.md).

Reading needs no account. GitHub comments require an account and are public. Please omit patient-identifying information.

## Files

- `index.html`: self-contained reading site with chapter navigation and topic search.
- `manuscript.md`: downloadable complete reading text.
- `REVIEWING.md`: feedback guidance.
- `release.json`: edition identifier and content hashes.

Only the authored review package is included. Raw transcripts, VOD media, internal protocols, and private working records are not distributed here. Search-indexing restrictions are requests to crawlers, not access control; the repository and site are public.
